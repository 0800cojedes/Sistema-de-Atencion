Error de conexión

No se pudo cargar la librería de Supabase desde el CDN.

Pasos para solucionar:
  1. Verifique su conexión a internet
  2. Recargue la página (Ctrl+F5)
  3. Si usa un bloqueador de anuncios, desactívelo temporalmente
  4. Intente desde otra red o navegador

Error de configuración

No se pudo conectar al proyecto de Supabase.

Error desconocido
Verifique en su panel de Supabase:
  1. El proyecto esté activo y no pausado
  2. La URL y clave anónima sean correctas
  3. Las tablas interacciones, atenciones e inventario existan
  4. Las políticas RLS permitan lecturas/escrituras con la clave anónima
